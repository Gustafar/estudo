# Caderno CGU

App de estudos para o concurso da CGU (Auditor Federal de Finanças e Controle, TI – Ciência de Dados, Edital nº 1 – CGU – AFFC, de 8/10/2026).

Site estático: abra `index.html` no navegador, ou publique a pasta (GitHub Pages, Netlify, etc.).

- Mapa do edital com tópicos por matéria
- Questões de múltipla escolha, cartões com repetição espaçada, discursiva e timer de foco
- Progresso salvo no navegador de cada pessoa (use Backup/Restaurar no menu para mover entre aparelhos)

O conteúdo (questões, cartões, gabaritos) é material de estudo escrito para este projeto; confira com o edital e as fontes oficiais.
